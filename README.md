## 📌 Tentang Proyek
Sistem Informasi Bank Sampah ini dikembangkan untuk mempermudah pengelolaan manajemen bank sampah secara terkomputerisasi. Proyek ini dibangun sebagai bagian dari penyelesaian tugas akhir / skripsi menggunakan framework **CodeIgniter 4**.

## ✨ Fitur Utama
* 👤 **Manajemen Nasabah & Petugas**: Pengelolaan data pengguna dan hak akses.
* 🗑️ **Kategori & Harga Sampah**: Pengaturan jenis sampah beserta nilai jualnya secara real-time.
* 📦 **Pencatatan Transaksi**: Perekaman setoran sampah dari nasabah yang dikonversi ke dalam saldo tabungan.
* 📊 **Laporan & Dashboard**: Rekapitulasi data transaksi harian, bulanan, dan tahunan untuk admin.

## 🛠️ Teknologi yang Digunakan
* **Backend:** PHP 8.2+
* **Framework:** CodeIgniter 4
* **Database:** MySQL
* **Frontend:** Bootstrap / CSS Framework
